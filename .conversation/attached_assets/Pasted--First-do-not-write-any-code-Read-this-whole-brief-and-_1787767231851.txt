  structure and the section order. Ask me clarification questions if anything is ambiguous.
  I will approve the plan before you build.

  Build a single-page, mobile-first marketing website for an event venue.
  The site content is in SERBIAN. Your code comments and variable names in English.

  HARD TECHNICAL CONSTRAINTS, do not violate:
  - Static site only. One index.html, one styles.css, one script.js. Nothing else.
  - NO backend, NO Express, NO database, NO user accounts, NO build step, NO npm packages.
  - No external CDN for fonts or scripts. Use system font stacks or embed what you need.
  - It must run by opening index.html directly in a browser and deploy to Netlify as-is.
  - If you are tempted to add a server or a framework, do not. This is intentionally a flat site.

  THE VENUE:
  Name: Happy Hill
  Location: Bocke, Sremska Kamenica, near Novi Sad, Serbia
  What it is: a private estate with an enclosed glass-walled hall, a pool, gardens, a gazebo
  and an apartment for the guests of honour. It hosts weddings, birthdays, christenings,
  engagements, anniversaries, corporate gatherings and team building. Booking-based, not walk-in.
  Stated capacity: roughly 100 to 200 guests.

  THE ONE SENTENCE THAT DRIVES THE WHOLE SITE:
  Happy Hill is a sunny, private space in greenery above Novi Sad, where a celebration feels
  like spending the day in a garden, with the safety of an enclosed hall.
  Do not sell it as a generic "banquet hall". The differentiator is the combination of
  nature, glass hall, view, pool, privacy and easy organisation.

  PLACEHOLDER DATA RULE, THIS IS IMPORTANT:
  The client has not confirmed phone number, exact capacity, inclusions or prices yet.
  - Put every unconfirmed value in a single CONFIG object at the top of script.js
    (phone, email, Instagram URL, Google Maps embed URL, address, capacity min/max).
  - Prefill them with obvious placeholders like "+381 6X XXX XXXX" and add a comment
    // TODO: confirm with client
  - NEVER invent prices, menus, package contents or reviews. If a section needs them,
    render a visible placeholder block instead.

  PAGE STRUCTURE, in this exact order:
  1. HERO, full viewport, one large background photo, dark gradient overlay at the bottom.
     Only: venue name, one short line of Serbian copy, and a primary button "Proverite termin".

  2. OSEĆAJ PROSTORA. Two or three short paragraphs about what the place feels like.
     Not company history. Generous whitespace.
  3. VRSTE PROSLAVA. A grid of cards: Venčanja, Rođendani i punoletstva, Krštenja i veridbe,
     Korporativna okupljanja i team building. Each card: photo placeholder, title, one line.
  4. PROSTOR I MOGUĆNOSTI. Icon list of features: staklena sala, bazen, zelenilo i bašta,
     letnjikovac, apartman za slavljenike, parking, plan B za kišu. Capacity stated from CONFIG.
  5. GALERIJA. A responsive masonry-style grid, 9 to 12 image slots, lightbox on click
     (write the lightbox yourself in plain JS, no library). Group by feeling, not by category:
     dan u zelenilu, postavka stola, atmosfera uveče.
  6. DOSTUPNI TERMINI. Build the SECTION SHELL ONLY, no calendar logic in this pass.

     month grid so the page rhythm is already correct.
     Under it, the permanent disclaimer, always visible:
     "Termin je upit, ne rezervacija. Javljamo vam se da potvrdimo dostupnost."
     Also include the primary button "Proverite termin" that scrolls to the contact form.
     Do NOT write any calendar code, do not create termini.json, do not invent dates.
     I will hand you the calendar as a separate task once this skeleton is approved.
  7. KAKO IZGLEDA DOGOVOR. Three steps: upit → obilazak i ponuda → potvrda termina.
     These are genuinely sequential, so numbering them is correct here.
  8. UTISCI GOSTIJU. Placeholder block that says reviews go here once the client supplies them.
     Do not write fake reviews.
  9. KONTAKT. Form fields: ime i prezime, telefon, email, vrsta događaja (select),
     željeni datum (date input), broj gostiju, poruka.
     Use a Netlify Forms compatible form: <form name="upit" method="POST" data-netlify="true">
     with the hidden form-name input. No JS submission handler, let Netlify take it.
     Client-side validation only for required fields and a valid email shape.

  VISUAL DIRECTION:
  - Palette: warm cream base, deep olive green, clay/ochre accent. Define as CSS custom
    properties on :root so a single edit changes the whole site.
  - Type: one editorial serif for headings, one clean sans-serif for body and labels.
    Set a clear type scale. Headings get text-wrap: balance.
  - Photography leads, text follows. Large images, lots of air, little copy.
  - Mobile-first. On a phone every action must be reachable one-handed, primary button
    never smaller than 48px tall.
  - Subtle fade-up on scroll via IntersectionObserver. Respect prefers-reduced-motion.

  DO NOT:
  - Do not use the black-and-gold "wedding hall" look.
  - No confetti, no script/cursive fonts, no stock photos of anonymous couples.
  - No aggressive animations, no autoplaying video with sound, no popups on load.
  - No cookie banner, no analytics, no tracking.

  IMAGES:
  Use local placeholder files in an /images folder with descriptive names
  (hero.jpg, sala-dan.jpg, bazen.jpg, sto-postavka.jpg, vece.jpg, ...).
  Generate simple coloured placeholder SVGs for now so the layout is visible without photos.
  Every img needs a meaningful Serbian alt text.

  ACCESSIBILITY AND QUALITY:
  - Semantic HTML5 landmarks, one h1, logical heading order.
  - Visible focus states on every interactive element.
  - Serbian latin text, proper diacritics (č, ć, š, ž, đ).
